    Conexión
    
        
    Cómo llega el celular hasta esta PC: por la red de casa, por Internet y con qué seguridad.
    
      
    

      
    
        
    Tu red y el firewall de Windows
    
        
    Para que el celular entre por el Wi-Fi de casa, Windows debe considerar esa red «Privada». Aquí ves cómo está y puedes arreglarlo. Cada botón pide permiso de administrador (NEXO debe estar abierto como administrador).
    
        
    Consultando el firewall…
    
        
      
        
      
        
      
        
      
          
          
          
          
          
        
      
      
      

      
      
        
      
          
      
            
      Entrar por HTTPS en la red de casa
      
            
      Añade un enlace «Casa segura», con candado, para el celular en tu Wi-Fi. Hace falta para usar el micrófono del celular sin salir a Internet. Abre el puerto 8443 en el firewall (sólo redes privadas). La primera vez el navegador avisa «conexión no privada»: acéptalo, el certificado lo creó esta PC.
      
          
      
          
        
      
        
      
          
          
        
      
      
      

      
      
        
      Internet en redes difíciles (TURN)
      
        
      Esta PC y tu celular con datos móviles suelen estar detrás de una red que impide la conexión directa; entonces NEXO cae al modo de imágenes (más lento). Un servidor TURN hace de puente y devuelve el vídeo fluido. Es opcional.
      
        
      
          ¿Qué servidor usar?
          
          
          
        
      

        
      
          
      
            
            
            En dash.cloudflare.com → Realtime → TURN Server → crea una clave.
          
      
          
      
            
            
            Cloudflare lo muestra una sola vez al crear la clave.
          
      
        
      

        
      
          
      
            
            
          
      
          
      
            
            
          
      
          
      
            
            
            Se guarda sólo en esta PC.
