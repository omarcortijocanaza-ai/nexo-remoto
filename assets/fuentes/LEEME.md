# Fuentes de las apariencias de NEXO

Archivos WOFF2 (subconjunto «latin», que cubre el español) descargados de [Google Fonts](https://fonts.google.com/)
con `node scripts/ui/descargar-fuentes.js`. Todas las familias se publican bajo la **SIL Open Font License 1.1**
([texto de la licencia](https://openfontlicense.org/open-font-license-official-text/)): se pueden usar, copiar y
redistribuir con el programa, siempre que no se vendan solas y se conserve este aviso.

| Familia | Se usa en | Ficha |
|---|---|---|
| Barlow · Barlow Condensed | Cabina | https://fonts.google.com/specimen/Barlow |
| JetBrains Mono | Cabina (cifras) | https://fonts.google.com/specimen/JetBrains+Mono |
| Cinzel | Rey Muerto (títulos y marca) | https://fonts.google.com/specimen/Cinzel |
| Atkinson Hyperlegible | Rey Muerto (texto) | https://fonts.google.com/specimen/Atkinson+Hyperlegible |
| Public Sans · DM Mono · Caveat | Cianotipo | https://fonts.google.com/specimen/Public+Sans |
| Bricolage Grotesque | Bloque | https://fonts.google.com/specimen/Bricolage+Grotesque |

Los derechos de autor de cada familia son de sus autores (ver cada ficha). `fuentes.css` declara los `@font-face`
con rutas relativas a esta carpeta.
